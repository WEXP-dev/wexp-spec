# Security

Security vulnerabilities in WEXP Core should be reported through GitHub Private
Vulnerability Reporting for this repository.

Use the repository's **Security** tab → **Report a vulnerability**. Reports stay
private to the maintainers until a fix or disclosure is agreed.

## Security-supported specification

    draft-sergeev-wexp-core-01

Earlier revisions are historical and are not security-supported.

## What helps in a report

The exact revision affected, the section or construct involved, the conditions
under which the issue arises, and its impact. Please do not include credentials
or unrelated private material.

## Scope

WEXP grades evidentiary strength for claims about execution. It does not certify
that an action was correct, safe, or aligned. A report about a specification
defect is in scope; a report that WEXP declines to certify something it never
claimed to certify is not.
